# Neo IT — Site Institucional

Site institucional da **Neo IT**, empresa de tecnologia especializada em soluções de infraestrutura, suporte técnico, desenvolvimento web, segurança da informação e serviços em nuvem.


## Páginas

| Página | Descrição |
|---|---|
| `inicio/` | Página principal com hero, serviços e depoimentos |
| `sobre/` | Missão, visão, valores e história da empresa |
| `servicos/` | Listagem completa dos serviços oferecidos |
| `drive/` | Produto Neo IT Drive — nuvem corporativa com IDS, IPS e WAF |
| `contato/` | Formulário de contato e canais de atendimento |


## Tecnologias utilizadas

- HTML5
- CSS3 (sem frameworks externos)
- JavaScript puro (Vanilla JS)
- Fontes: Bebas Neue (Bold, Regular e Light)

## Funcionalidades

- Layout responsivo com menu hamburguer para mobile
- Efeito parallax nas imagens de fundo
- Animações de scroll (reveal ao entrar na viewport)
- Efeito fumaça nos textos principais
- Popup de detalhes dos serviços
- Link direto para WhatsApp
- Navegação com destaque de página ativa


## Como executar localmente

Não é necessário instalar dependências. Basta clonar o repositório e abrir os arquivos no navegador, ou usar uma extensão como **Live Server** no VS Code.

git clone https://github.com/seu-usuario/neoit.git
cd neoit
